# 📰 Fake News Detection System

## 📖 Overview
This project is a Machine Learning based Fake News Detection system that classifies news articles as REAL or FAKE using a trained model.

The system includes a Flask web application where users can input news text and get instant predictions.

---

## 🚀 Features
- Fake vs Real news classification
- Machine Learning text processing
- Flask-based web interface
- Trained ML model using dataset
- Clean and simple UI

---

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- Pandas
- Joblib
- HTML / CSS
